# Moraes — Portfólio profissional

Site pessoal de Moraes, desenvolvedor backend especializado em .NET, C# e ASP.NET Core.

## Acessar

- GitHub Pages: https://gmmoraesbr.github.io/
- Publicação alternativa: https://moraes-backend.lmoraes.chatgpt.site/
- LinkedIn: https://www.linkedin.com/in/gm-moraes/

## Estrutura

O site está em `index.html`, com HTML, CSS e JavaScript no mesmo arquivo. Não há dependências ou etapa de compilação.

## Editar e publicar

Edite `index.html` e envie as alterações para a branch `main`. O GitHub Pages publica os arquivos da raiz dessa branch.

Para visualizar localmente, abra `index.html` no navegador.
